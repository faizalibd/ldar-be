# API LDAR

API Liason Design Action Request (LDAR) merupakan aplikasi untuk memudahkan dalam proses maintain dan mengakses Liaison Design Action Request  (LDAR) berdasarkan kebutuhannya masing masing. Fungsi atau modul yang terkait dengan Funcional Design ini adalah Production dan Engineering (ENG)

## How to use

set DEBUG=ldar-api:\* & npm run start_mon
